## 可视化故事
本项目以论文《Comprehensive mapping of local and diaspora scientists: A database and analysis of 63,951 Greek scientists》为基础数据来源，围绕“希腊科学家流失（Brain Drain）”这一核心议题，构建一个面向公众的数据叙事型可视化网站。
项目希望通过交互式可视化方法，展示：
• 希腊科学家在全球范围内的空间分布；
• 本土与海外科学家之间的影响力差异；
• 不同学科的人才流失结构；
• 顶尖科学家向海外集中的趋势；
• 年轻一代科学家是否持续外流；
## 可视化图表的选择
jyx故事线+可视化图表想法：
1. 柱状图+世界地图：展示希腊科学家当前所在国家的 Top 10，例如 Greece、USA、UK、Germany、Cyprus 等，按人数从高到低排序。回答的问题是：希腊科学家主要分布在哪些国家？
    ◦ Hover 国家查看详细信息；
    ◦ 点击国家联动更新其他图表；
    ◦ 世界地图作为仪表板主视觉，柱状图/散点图用于解释读者选择的重点信息；
2. 散点图或气泡图：横轴为论文数，纵轴为引用数或 h-index，颜色区分本土/海外，气泡大小表示学科内排名或 top percentile。回答的问题是：海外科学家的影响力更高，是因为发文更多，还是同等发文量下被引用更多？
    ◦ x轴：论文数量
    ◦ y轴：引用量 / h-index
    ◦ 颜色：本土 / 海外
    ◦ 气泡大小：Top percentile
3. 树图，结构可以是：本土/海外 → 22 个大类学科 → 174 个子学科。矩形面积表示科学家人数，颜色表示海外占比，悬浮时显示该子学科的本土人数、海外人数、Top 1% 人才数、中位引用数。
    ◦ 面积：科学家人数
    ◦ 颜色：国家成分（简化为国内/国外）
4. 国家—学科网络：左侧是国家节点，右侧是学科节点，边表示某国拥有该学科的希腊科学家，边宽表示人数，颜色表示学科大类。回答的问题是：不同国家承接了哪些学科的人才？
或热力矩阵：行是国家，列是学科，格子的颜色表示人数或 Top 1% 人数。
5. 盒须图/山脊线图 + log尺度。回答的问题是“海外科学家影响力是否更高？”故事是引用分布长尾明显，海外在高影响力端更突出。
6. 按地理区位/语言区/经济发展水平，对各个国家进行聚类，看它们之间的区别？
## 页面排布与交互
交互式仪表盘（Interactive Dashboard）和单页面滚动叙事（Scrollytelling）相结合的形式。
不同于传统静态图表展示，本项目强调：
• 图表之间的联动；
• 用户主动探索；
• 动态筛选与比较；
• 滚动触发的叙事切换；
用户在浏览过程中，可以通过：
• 国家筛选；
• 学科筛选；
• Top percentile 筛选；
• 本土/海外切换；
动态观察不同层面的人才流失现象。

页面顶部将作为整个项目的主视觉区域，集中展示：
• 全球希腊科学家分布地图；
• Top 国家统计；
• 海外/本土科学家比例；
• 顶尖科学家数量；
• 学科整体结构；
并提供全局筛选器，用户的筛选操作将同步联动更新所有图表，实现整体数据探索。
具体实现为（重点，大家提些建议）
• 顶部有学科、Top percentile、
• 中间展示世界地图（主视觉），颜色深浅表示科学家总数（或者已选定的特定学科的科学家的总数）；
• 左侧：信息概览卡片（Overview Cards）用于展示当前筛选条件下的核心统计信息；卡片内容包括：
    ◦ 当前国家中的希腊科学家总人数；
    ◦ 全球占比；
    ◦ Top 1% 科学家人数；
    ◦ 平均 citation；
    ◦ 平均 h-index；
    ◦ 最主要学科；
• 地图右侧：横向柱状图展示国家排名，地图展示空间感，bar chart负责展示具体排名；
• 底部：上半部分展示了“全球空间结构”，将叙事自然推动到本土/海外的对比

在用户向下滚动页面时，网站将进入分章节的数据叙事模式；
• 第一部分：全球扩散：展示希腊科学家的全球空间分布。
• 第二部分：影响力差异：比较本土与海外科学家的 citation、h-index 与 Top percentile 分布。
• 第三部分：学科结构：分析不同学科的人才流失情况，以及不同国家分别承接了哪些科研方向的人才。
• 第四部分：顶尖人才迁移：重点展示 Top percentile 科学家向海外集中的现象。
• 第五部分：下一代科学家：从学术年龄角度分析年轻科研人员是否仍在持续外流。
